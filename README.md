## ⚡ Overview

**FitPulse AI** is a modern, full-stack fitness application designed to deliver real-time, interactive fitness coaching. Leveraging voice AI and Large Language Models, FitPulse AI conducts conversational assessments with users to dynamically generate personalized workout routines and custom diet recommendations.

---

## ✨ Key Features

- **🎙️ Real-time Voice Consultation**: Talk directly with an AI fitness assistant (powered by Vapi) that collects your goals, physical condition, and preferences through dynamic conversation.
- **🏋️ Tailored Workout Plans**: Receive personalized, highly specific exercise routines tailored to your fitness level, available equipment, and injuries.
- **🥗 Custom Diet Recommendations**: Get instant meal plan suggestions aligned with your calorie needs, allergies, and nutritional preferences.
- **🎬 Dynamic Program Generation**: Real-time generation of custom fitness programs stored and updated seamlessly.
- **🔒 Secure Authentication**: Multi-provider login (GitHub, Google, Email/Password) powered by Clerk.
- **💾 Real-time Database**: Lightning-fast data synchronization and program persistence using Convex.
- **📱 Fully Responsive UI**: Sleek, cyber-inspired design optimized for desktop, tablet, and mobile viewing.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router, Server Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [Shadcn UI](https://ui.shadcn.com/)
- **AI Models:** [Google Gemini AI](https://ai.google.dev/) (LLM Logic) & [Vapi AI](https://vapi.ai/) (Voice Agent)
- **Database:** [Convex](https://www.convex.dev/) (Real-time Backend)
- **Auth:** [Clerk](https://clerk.com/)
